# Reference imagery

Drop intraoperative photos and video stills here, named by what they show, e.g.
`skin-prepped-chg.jpg`, `fat-lobules-open-wound.jpg`, `coag-blanch-3s-30w.jpg`,
`char-eschar.jpg`, `deep-fascia-glisten.jpg`, `arterial-bleeder.jpg`, `lipoma-capsule-plane.jpg`.

Only use images you have the right to use (your own, de-identified, or openly licensed).
They are not committed to the repository by default (see .gitignore) unless you choose to.
