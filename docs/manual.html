About this simulator

The tissue is a 3D grid of small cubes (0.25 mm by default), each one skin, dermis, fat, septum, fascia, muscle, artery, vein, nerve or lipoma. When you activate, the simulator solves the electrical field from the electrode to the return pad, turns current into heat, conducts that heat through tissue with blood cooling it, boils water off, and tracks protein damage over time. That is what decides whether tissue blanches, dries, chars or is vaporised, and whether a vessel seals or just gets a char plug.

Each scenario has a goal, a definition of success, failure points, decisions you will have to make, and things you cannot know in advance (fat thickness, where the perforators are). The event feed explains what just happened and why, in surgical terms.

Warning

This is a training aid. Generator behaviour and tissue values are modelled approximations, not the manufacturer's specification. Always follow the Valleylab FT10 user guide, your hospital's policies and your supervising surgeon in real cases.

Part 1 takes you from a new Windows PC to a running simulator. Part 2 explains how to operate it, starting with a guided first session.

Part 1Installation

Get the files

The project lives on GitHub at github.com/atate911/boviesim. It is one folder containing the Unity application (unity\BovieSim), the shared scenarios and the browser version. Sign in to GitHub first if the repository is private.

  1. Choose a short folder such as E:\claude or C:\dev. Keep it out of OneDrive, Documents and Desktop: Unity creates deeply nested files, Windows refuses paths over 260 characters, and OneDrive syncing them slows everything down. The rest of this manual uses E:\claude.
  2. Either clone it with Git (recommended, so updates are one command): install Git for Windows, open a terminal in E:\claude and run git clone https://github.com/atate911/boviesim bovie-sim. To update later, run git pull inside E:\claude\bovie-sim with Unity closed.
  3. Or download a zip: on the GitHub page choose Code → Download ZIP, right-click the zip → Extract All… into E:\claude, and rename the extracted boviesim-main folder to bovie-sim.
  4. Check the path. You should now have E:\claude\bovie-sim\unity\BovieSim, containing Assets, Packages and ProjectSettings.

Open and set up the project

This happens once. Allow 15–30 minutes the first time. Most of it is Unity importing files and downloading its rendering packages, with progress bars and few questions. Each step below says what you should see.

  1. Add the project to Unity Hub. Projects → Add → Add project from disk → select the folder E:\claude\bovie-sim\unity\BovieSim (the one that contains Assets, Packages and ProjectSettings).
    You should see: BovieSim appears in the Projects list with an editor version beside it. Hub asks nothing else at this point; adding only lists the project. If the version is shown with a warning, click it and choose your installed 6000.6 version.
  2. Open it. Click BovieSim in the list.
    You should see: the Unity editor starts and shows Importing and Compiling scripts progress bars for several minutes. If Windows Firewall asks about the Unity editor, allow it.
  3. Open the Console. Once the editor window is up, choose Window → General → Console (Ctrl+Shift+C) and keep it visible. Bovie Sim reports its progress there.
  4. Let the packages install. Nothing to click. Bovie Sim installs HDRP (the renderer), the Input System (for the pen) and the Test Framework.
    You should see: [Bovie Sim] Installing packages… in the Console, then more progress bars while Unity downloads and compiles them, then [Bovie Sim] Packages installed. A Bovie Sim menu appears in the menu bar. The HDRP Wizard window may open by itself; leave it for now.
  5. Accept the input restarts. When the Input System arrives, Unity asks whether to enable the new input backends. Choose Yes; the editor restarts. After it reopens, Bovie Sim says Active Input Handling was changed to 'Both': choose Restart now.
  6. Run setup. After the restart a Bovie Sim dialog asks Set up the project now?. Choose Set up. If no dialog appears, choose Bovie Sim → Set Up Project from the menu bar.
    You should see: a Bovie Sim setup progress bar going through the HDRP asset, diffusion profiles, 18 tissue textures, materials, the downloads and the scene, then [Bovie Sim] Setup complete. in the Console.
  7. Fix renderer warnings if any. Open Window → Rendering → HDRP Wizard. If it lists problems, press Fix All, then run Bovie Sim → Set Up Project again.
  8. Open the scene. In the Project panel go to Assets/BovieSim/Generated and double-click Main. You are ready to run it: see Starting and stopping.

Set up a Wacom pen

A mouse is enough to use the simulator. A pen adds depth control and instrument angle.

  1. Install the Wacom driver from wacom.com if it is not already installed.
  2. Keep Windows Ink on. Open Wacom Tablet Properties → Mapping and make sure Use Windows Ink is ticked. Unity only receives pen pressure and tilt through Windows Ink.
  3. Check it in the simulator. Hover the pen over the skin: the instrument should lean with the pen. Press lightly and then firmly: the electrode sits deeper with more pressure (0.15 to 1 mm).
  4. Fix the direction if needed. If leaning the pen toward you tips the instrument away from you, press Y.

Build a standalone app

Optional. A build runs without the Unity editor, starts faster and can be copied to another Windows PC with a suitable graphics card.

  1. Open the build window. In Unity choose File → Build Profiles. Select Windows (it is the default platform on a Windows PC). The scene list should show Main; Set Up Project adds it.
  2. Build. Click Build and choose a new, empty folder such as E:\claude\BovieSimApp. The first build takes several minutes.
  3. Run it. Open that folder and double-click BovieSim.exe. If Windows SmartScreen warns about an unknown app, choose More info → Run anyway; the build is not code-signed.
  4. Copy the whole folder to move it to another PC. The .exe needs the BovieSim_Data folder and UnityPlayer.dll beside it.

In the built app, F11 switches between fullscreen and a window and Esc quits.

Part 2Operation

Starting and stopping

In the Unity editor

  • Open Main.unity, then press the Play button at the top (or Ctrl+P).
  • Click once inside the Game view so it receives the keyboard.
  • For a full-size view, choose Play Maximized from the Game view's toolbar.
  • Press Play again (or Ctrl+P) to stop.

As a built app

  • Double-click BovieSim.exe.
  • F11 toggles fullscreen.
  • Esc quits.

On start the screen shows Building anatomy… for a few seconds while the tissue bed is generated, then the field appears with the scenario brief open.

Choosing a scenario and quality

  • F6 moves to the next scenario; F5 restarts the current one.
  • To start in a particular scenario or change detail, stop Play, select the Bovie Sim object in the Hierarchy and set Scenario Id (freeplay, hemostasis or lipoma) or Voxel Override (0 = full 0.25 mm detail; 0.4–0.5 runs faster).
Caution

Unity discards changes made to objects while Play is running. Change Scenario Id and Voxel Override only while stopped.

Your first session

A guided 10-minute run in the free-play bed. It shows a clean incision, what fat does to cut mode, how to stop a bleeder properly, and two common mistakes.

Make an incision

  1. Start free play. Press Play. Read the goal in the brief, then press F1 to hide it.
  2. Find a view. Right-drag to look around and use the wheel to zoom until the skin fills most of the screen.
  3. Check the generator. The FT10 panel (bottom right) should read PURE 30 and FULGURATE 30.
  4. Touch the skin. Move the cursor onto the skin. The pencil appears with the blade on the surface, and the status readout shows under tip: Epidermis.
  5. Cut. Hold Z (cut pedal) and draw the cursor across the skin at a steady pace, about 3 cm in 3 seconds. Release Z at the end. While cutting, the readout shows impedance Z and delivered power P close to 30 W.
  6. Measure the edge. Press C twice so the section view shows damage. Hover over the incision: the pale band beside the cut is the thermal rim. The goal is under 0.5 mm.
  7. Go deeper. Cut along the same line again until the yellow fat shows. The event feed reports tissue.fatContact: cut mode sputters in fat, so move faster or switch to Blend (2).

Control a bleeder

  1. Find one. If you cut across a perforator, the feed reports bleed.start and blood starts to pool. Bright red and pulsing is arterial.
  2. Clear the field. Press Tab twice for the suction. Hold the left mouse button over the pool until you can see the vessel end.
  3. Grasp. Press Tab three times to get back round to the forceps. Hold the left mouse button with the jaws on the vessel end.
  4. Buzz. Keep holding and press X (coag pedal) for about a second. The feed reports forceps.buzzed and then bleed.sealed. Release.

Make the classic mistakes

  • Char. Switch back to the pencil, hold it still on intact skin and hold X for 3 seconds. The tissue blanches, then dries, then turns black: tissue.carbonized. Watch P fall as Z rises.
  • Char plug. On a bleeding vessel end, coagulate directly with the pencil instead of the forceps. It may look controlled (bleed.charPlug), then rebleed (vessel.rebleed).

Press F5 to start again, or F6 to move on to the hemostasis drill.

Delivering the lipoma

In the lipoma scenario, incise the skin over the lump, deepen to the shiny capsule, then cut around it, staying on the capsule surface and going deeper each pass. A needle (N) at lower power gives more control. The status readout counts the capsule links still attached. When it shows FREE, change to the forceps, grasp the lipoma and hold Space to lift it. It is delivered once it rises 4 mm out of its bed.

Generator and modes

The FT10 holds the set power steady across a band of tissue impedance. Below the band (wet tissue, blood) it is current-limited and delivers less. Above it (dry tissue, fat, char) it runs out of voltage and delivered power falls. Watch the Z and P readouts: when Z climbs past the band and P drops well below your setting, the tissue under the electrode has dried out.

ModeMaxConstant-power bandPeak voltageDutyArc reachWhat it does
Pure300 W100–2000 Ω1.6 kV100 %0.13 mmContinuous wave. Vaporises cells ahead of the blade with the narrowest thermal rim. Little hemostasis.
Blend200 W100–1500 Ω2.2 kV50 %0.33 mmInterrupted cut. Some coagulation along the edge; a wider rim than Pure.
Low200 W100–600 Ω1.2 kV100 %0.06 mmLow-voltage cut for fine work. Stalls in high-impedance tissue.
Valleylab300 W100–2000 Ω2.0 kV60 %0.30 mmCut with hemostasis, between Pure and Blend.
Fulgurate120 W200–3000 Ω4.5 kV6 %2.0 mmHigh-voltage bursts. Sparks to the surface and coagulates oozing; chars if held.
Spray120 W300–4000 Ω6.0 kV4 %3.6 mmHighest voltage, widest spark spread. Superficial coagulation over an area.

Arc reach is how far a spark can jump from the electrode to tissue in that mode. In coag modes the electrode does not need to touch. In cut modes it does: activating in the air does nothing useful.

Note

These values are the simulator's model of the FT10, chosen to reproduce its behaviour. They are not taken from the Valleylab specification sheet.

REM. The panel's REM lamp shows the return-pad monitor. A REM fault stops the generator from activating, as on the real unit.

Instruments

Bovie pencil

Blade (B), needle (N) or ball (O) electrode. The tip follows the tissue surface under the cursor; pen pressure pushes it deeper (0.15 to 1 mm). The hand-switch buttons glow when active.

  • Blade: incisions. Roll it with R to cut with the edge or coagulate with the flat.
  • Needle: fine dissection, concentrated current.
  • Ball: broad surface coagulation.

Adson forceps

Hold the left mouse button to close the jaws. Closed jaws can:

  • Grasp a vessel and press its walls together.
  • Buzz: press a pedal while grasping and the jaws become the electrode. This is how you seal a vessel.
  • Lift tissue: hold Space while the jaws are closed. A freed lipoma comes up with them.

Open jaws cannot be activated. T switches toothed and smooth.

Frazier suction

Hold the left mouse button to suck. It drains blood within about 2.5 mm of the tip and pulls in smoke. Clear the pool before you look for the bleeder.

Skin hook

Press on the skin edge to catch it, drag to retract, release to let go. The tissue stretches and the wound opens.

Technique in the sim

Cutting skin

Touch first, then activate. In Pure cut at about 30 W, keep the blade moving at a steady pace. Pausing, moving slowly, or using coag on the skin edge widens the thermal rim. The scenarios ask for a rim under 0.5 mm: check it in the section view in the damage display.

Fat

Fat has high impedance and little water. Cut mode sputters and stalls in it. Move faster, use Blend, or dissect bluntly.

Controlling a bleeder

  1. Clear the field. Suction the pool. Energy into a pool spreads through the blood and seals nothing.
  2. Find the source. Bright red and pulsatile is arterial; dark and welling is venous.
  3. Grasp the vessel with the forceps, tips on the vessel only.
  4. Buzz the forceps: press the coag pedal (X) while holding the jaws closed. The walls are pressed together as they coagulate, which gives a seal that holds.
  5. Decide on a tie for vessels over about 2 mm. Ties are a decision point in the scenarios; they are not yet a hands-on action.
Caution

Coagulating an open vessel end directly with the pencil leaves a char plug, not a seal. It can look controlled and rebleed seconds later. The simulator models this on purpose.

Char

Black char is dry tissue that no longer conducts. More energy only spreads heat sideways. Lift off, lower the power, and use short taps.

Scenarios

Press F6 to move between scenarios, or set Scenario Id on the Bovie Sim object in the scene. Each starts with Pure cut and Fulgurate coag; the watts are suggestions you can change.

freeplay · 30 W cut / 30 W coag

Free-play tissue bed

Full-thickness bed with skin, fat with septa and perforators, Scarpa's fascia, deep fascia and muscle. A small lipoma sits off-centre.

Goal
Explore each mode on each layer. Make a clean 3 cm incision through dermis with a thermal rim under 0.5 mm, then control any bleeder you expose.
Success
  • Skin edge thermal rim < 0.5 mm
  • Less than 5 mm³ of char
  • Blood loss under 5 ml
Decision
At the deep fascia: stay above it, or go through into muscle?
Uncertain
Fat thickness varies ±15 %, so the fascia depth is not known. Perforator positions change every attempt.
hemostasis · 30 W cut / 35 W coag

Hemostasis drill

An open trench through skin and fat crosses two perforating vessels, one of them arterial.

Goal
Stop both bleeders with less than 5 ml blood loss and no char plug left behind.
Success
  • Blood loss under 5 ml
  • No active bleeding
  • No char plug relied upon
Decision
The bleeder is about 1 mm: buzz the forceps (reliable up to about 1.5–2 mm when the walls are pressed together) or tie it?
Uncertain
You cannot tell which vessel is arterial until it bleeds. Small extra perforators may sit in the trench wall.
lipoma · 30 W cut / 30 W coag

Lipoma excision

A 14 × 12 mm subcutaneous lipoma 3 mm under the skin.

Goal
Excise it intact: incise along Langer's lines, dissect on the capsule, free it all the way round, deliver it with forceps, control bleeding.
Success
  • Lipoma delivered
  • Capsule never entered with energy
  • Skin edge thermal rim < 0.5 mm
  • Blood loss under 10 ml
Decisions
A feeder at the base bleeds: grasp and buzz, or tie? At the deep fascia under the lipoma: stay above it.
Uncertain
The capsule extends 1–2 mm beyond the palpable edge. The feeder's position is unknown until you lift the lipoma.

In the lipoma case, the status readout shows how many capsule links are still intact. Once most of them are cut, it reads FREE and the event feed reports lesion.freed. Grasp with the forceps and hold Space to lift: lesion.delivered fires when it has risen 4 mm out of its bed.

Section view displays

Press C to cycle: tissue (layers and states), temperature, damage (protein denaturation; blanching starts above 0.53), water (drying), potential (the electrical field) and current density. Use damage to measure the thermal rim beside an incision.

Reporting a problem

Send these and the fix can be made without guessing:

  • The first error from the Console, copied exactly (file, line and message). Right-click the Console tab → Open Editor Log gives the full log if needed.
  • What you were doing, and the scenario.
  • A screenshot of the Game view for anything visual: tissue colours, lighting, smoke or blood that looks wrong to a surgeon's eye.
  • Your graphics card (Task Manager → Performance → GPU) and Unity version.

Visual realism is tuned against your judgement. If something does not look the way it does in theatre, describe what you expect to see.
